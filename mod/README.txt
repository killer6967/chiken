Обиженная земля — Fabric 1.21

СБОРКА ЧЕРЕЗ GITHUB (без установки чего-либо):
1. Создай репозиторий на github.com и загрузи в него ВСЕ файлы из архива
   (включая папку .github).
2. Открой вкладку Actions -> дождись зелёной галочки (2-5 минут).
3. Открой завершённый запуск -> внизу "Artifacts" -> скачай offended-dirt-jar.
4. Внутри лежат два jar. Нужен тот, что БЕЗ "-sources" в названии.
5. Положи его в папку mods вместе с Fabric API для 1.21.

СБОРКА НА КОМПЬЮТЕРЕ:
Нужны Java 21 и Gradle 8.8+. В папке проекта: gradle build
Jar будет в build/libs.

Для игры нужны: Minecraft 1.21, Fabric Loader 0.16+, Fabric API 0.102.0+1.21.
